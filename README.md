# My_Dotfiles
These are the Dotfiles I use on my Arch + Hyprland Setup, plus what you need to install and how to.

# The Packages 
You'll need to install some Packges, in order to get everything working. I use the archinstall script whenever I'm installing Arch, so some critical essential Packages might not be here. If you interrested in what I choose in that process, here's a list:

Archinstall Things:
Locale: en_GB UTF-8
Type -> Desktop: Hyprland
Login Manager: ly
Audio: pipewire
Firewall: ufw
Printer Service: YES
...
Timzone, Keyboard Layout, User Account, Passwords are your choice.
